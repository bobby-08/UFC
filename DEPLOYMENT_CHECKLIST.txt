DEPLOY THE PROJECT

[x] Copy .env.example to .env.
[x] Set AIRFLOW_UID to the output of `id -u`.
[x] Set separate random values for POSTGRES_PASSWORD and AIRFLOW_JWT_SECRET in .env.
[x] Build the Docker image with `sudo docker compose build`.
[x] Initialize Airflow once with `sudo docker compose run --rm airflow-init`.
[x] Start the containers with `sudo docker compose up -d`.
[x] Confirm services are running with `sudo docker compose ps`.
[x] Retrieve the generated Airflow password from the API server container.
[x] Open an SSH tunnel to VM port 8080 and visit http://localhost:8080 locally.
